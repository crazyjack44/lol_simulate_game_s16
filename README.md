# S16 全球总决赛 · 策略对决

> Worlds Strategy Clash — 一款纯前端、离线可玩的英雄联盟 S16 全球总决赛策略模拟小游戏。

执教 16 支真实参赛战队之一，从积分赛一路打到决赛，用赛前的**阵容体系**与**团战风格**决策影响程序推演的战局，观看小龙/大龙团战动画与选手 ID 级击杀播报，最终捧起召唤师杯。

## ✨ 主要功能

### 🎮 完整赛事流程

选队 → 赛场 → 决策 → 推演 → 赛果 → 加冕，六大屏幕一屏到底：

- **积分赛**（8×BO1）→ **八强**（1v8 / 4v5 / 2v7 / 3v6 对阵）→ **半决赛** → **决赛** → **冠军加冕**
- 顶部赛程进度条实时显示当前阶段，支持快速模拟与阶段推进

### 🏆 真实 S16 参赛名单

- 16 支真实战队（GEN、HLE、T1、DK、AL、BLG、TES、iG、TL、C9、G2、KOI、KC、LYON、FLY、SR），完整五路选手名单
- 数据取自各赛区最新赛段雷达（LPL Split 3 / LCK Rounds 3-4 / LEC·LCS Summer）
- 真实选手照片、战队 Logo、英雄图标全部本地化，无任何网络依赖

### 📊 队伍雷达与选手卡

- 选队界面点击任意战队即见 **8 维队伍雷达叠图** + 五路选手照片墙
- 选手卡展示位置、ID、真实赛段雷达数据与战力评分
- 战力由雷达数据映射（`power = clamp(70, 96, radarPower + 修正)`），强弱有据可依

### 🧠 战前决策（你的唯一操作层）

| 决策 | 选项 | 说明 |
| --- | --- | --- |
| **阵容体系** | 版本常规 / 招牌体系 / 冷门奇招 | 从稳健到高风险高回报：招牌体系达成联动可解锁强力团战技能；冷门奇招命中则爆炸加成、落空则自减益 |
| **团战风格** | 强开团 / 四保一 / 分带拉扯 / 正面团 | 四风格循环克制（强开团 → 四保一 → 正面团 → 分带拉扯 → 强开团），克制关系直接进入结算系数 |

BO5 进行中还可**中途调整战术**，用新战术打完剩余局数。

### ⚔️ 程序化对局推演

- **六因子事件预测**：阶段 / 风格 / 经济 / 战力 / 势头 / 对位，softmax 归一化后抽取事件
- 事件自带自然克制（前期：入侵 > 对线 > 埋伏 > 入侵；龙团：抢龙 > 绕后 > 蹲守 > 抢龙）
- **预测面板可解释性**：Top3 事件概率条 + 六因子数值 + 实际抽取结果对照
- **BO5 赛制**（先胜 3 局），动画播放首局 BO1，可一键看完整系列赛结果

### 🔥 团战 Canvas 动画（签名时刻）

- 小龙/大龙团条件触发，单位头像 + 真实选手 ID 上场
- 弹道粒子、技能闪屏、死亡日志
- **击杀播报**：一命一人不重复，选手 ID 级战报实时滚动
- 配套解说文本流，回放式观战体验

### 🎵 沉浸式观赛体验

- LOL Worlds 主题视觉：深空底 + 金色描边斜切面板 + 红蓝方高饱和对位
- 赛事标题图、BGM 播放器（顶栏开关，Rise 风格史诗配乐）
- 积分榜、对阵网格、赛果数据面板、复盘与冠军加冕演出

## 🚀 快速开始

纯静态页面，**无需构建、无需安装依赖、无需联网**：

```bash
# 方式一：直接双击打开
index.html

# 方式二：本地起个静态服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

浏览器要求：支持 ES2020 的现代浏览器（Chrome / Edge / Firefox / Safari 均可）。

## 🗂 项目结构

```text
├── index.html              # 页面骨架（七屏 DOM）
├── css/style.css           # Worlds 主题样式
├── js/
│   ├── roster.js           # 生成物：真实名单 + 雷达（由脚本抽取）
│   ├── data.js             # 队伍配置、阵容体系、风格、事件、文案
│   ├── radar.js            # 雷达绘制 API
│   ├── engine.js           # 预测 / 模拟 / 团战 / 击杀 feed / 抽签
│   ├── anim.js             # 团战 Canvas 动画
│   └── game.js             # 流程与 UI 交互
├── assets/                 # 选手图 / 队标 / 英雄图标 / UI / BGM（全本地）
├── data/rosters.json       # 名单数据源
├── scripts/
│   ├── extract_roster.py   # 从赛段雷达数据生成 js/roster.js
│   └── copy_assets.py      # 素材本地化拷贝
├── smoke.js                # 引擎回归测试
├── smoke-dom.js            # 端到端流程冒烟测试
└── check-dom.js            # DOM id / 脚本顺序对齐检查
```
