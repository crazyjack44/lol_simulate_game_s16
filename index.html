Product Spec · Web Game

场内策略对决系统

取材自《英雄联盟电竞经理》场内策略对决的网页简化版。你执教 S16 全球总决赛16 支真实参赛战队之一，征战积分赛 → 八强 → 半决赛 → 决赛。 对局内不设事件卡——由程序按概率、战力、经济与风格叠加推演并预测下一步事件走向， 赛前你只定阵容体系与团战风格。

产品定位 OVERVIEW

纯前端离线可玩：HTML + CSS + 原生 JavaScript。战队战力与选手雷达来自 lol-radar-titan 最新赛段（LPL Split 3 / LCK Rounds 3-4 / LEC Summer / LCS Summer）， 选手图、战队 Logo 与英雄图标均已本地化，不依赖 CDN。

核心体验 CORE

赛前决策影响事件概率与战力系数；UI 展示概率条与六因子，对照实际抽取；小龙/大龙团 Canvas 动画；选手 ID 级击杀播报。

相对完整版的简化 DIFF

完整 Ban/Pick → 赛前三选一阵容体系；玩家事件卡取消；装备经济并入系数；六回合沙盘 → 三节点；手动技能 → 程序自动释放。

三层系统 SYSTEM

阵容：版本常规 / 招牌体系 / 冷门奇招。
推演预测：phase·style·economy·power·momentum·vs → softmax。
自动团战：技能时机 + 击杀 feed。

赛事结构 FORMAT

积分赛 8×BO1（胜 3 分）→ 八强 1v8 / 4v5 / 2v7 / 3v6 → 半决赛 → 决赛 → 冠军加冕。

操作指南 HOW

选主队看雷达 → 进入赛场 → 亲自指挥一场（只选阵容+风格）→ 观看推演与团战 → 读赛果复盘 → 可模拟剩余比赛并推进阶段。

数值框架 MATH

power = clamp(70, 96, radarPower + Δ)。克制环：强开→四保一→正面→分带→强开。事件环：入侵→稳健→埋伏；速杀→包抄→蹲伏。

技术实现 TECH

脚本顺序：roster → data → radar → engine → anim → game。校验：node smoke.js / check-dom.js。
